git-grass Developer Documentation

git-grass is an outdoor break enforcement engine built directly into your Git workflow. Use it to disconnect from code, touch grass, and verify your commit when you return.

What you can do with git-grass

Explore core capabilities designed to protect developer well-being without compromising Git repository integrity.

Understand your repo

Analyzes staged file extensions, commit messages, and project frameworks to synthesize context-aware outdoor observation prompts.

Enforce focus intervals

Configurable interval timers (default 60m) intercept git commit when due, preventing marathon screen burnout.

Staged-tree fingerprint

Computes SHA-1 hash via git write-tree upon break initiation. Guarantees zero code modifications while you are outdoors.

Hosted AI challenges

Uses Render-hosted API powered by Backboard with strictly ₹0 additional spend. Automatically falls back to offline catalog if offline.

Phone-free reflection

Authoritative 10-minute minimum walk timer with physical observation check-ins. Zero biometric surveillance or geofencing.

Safe commit unlock

One tap from your phone browser unblocks your workstation, commits the exact fingerprinted tree, and optionally auto-pushes.

Prerequisites

git-grass is designed to run locally with zero native toolchain dependencies:

  • Node.js: Version 18.0.0 or later (verified across Node 18 LTS, 20 LTS, and 22).
  • Git: Version 2.20 or later accessible in your operating system PATH.
  • Operating System: macOS (Apple Silicon / Intel), Linux (glibc and musl), or Windows 10/11 (PowerShell and Git Bash).
  • Local Network: Workstation and mobile device connected to the same Wi-Fi router or personal mobile hotspot for QR session pairing.
  • Zero Local AI Requirements: No Ollama, no Docker, no Python, and no GPU setup required.

Quickstart Tutorial

Get up and running in under 60 seconds with three simple steps:

bash — quickstart 
# 1. Install CLI globally
npm install -g git-grass

# 2. Enter any Git repository
cd my-project

# 3. Initialize git-grass break gate
git grass init

Once initialized, work on your project normally. When you reach your configured focus threshold and run git commit, git-grass prompts you to step outside, provides a QR code, and unlocks automatically upon your return.

CLI Installation Options

Choose the installation path that matches your development workflow:

Option A: Global NPM Package (Recommended)

bash — npm global 
npm install -g git-grass

Option B: Ephemeral Execution via NPX

bash — npx 
npx git-grass init

Option C: Clone & Build from Source

bash — source build 
git clone https://github.com/sn3hhaa/git-grass.git
cd git-grass
npm install
npm run build
npm link

CLI Commands Reference

Every command supports --help for inline usage flags. Below is a comprehensive breakdown of all commands.

git grass init [--force]

Setup

Installs the pre-commit hook gate and configures repository thresholds. Safe to run multiple times. Preserves pre-existing linters and formatters.

terminal — init 
$ git grass init
[git-grass] Initializing repository hook gate...
[git-grass] Created .git-grass/config.json with default thresholds.
[git-grass] Installed hook wrapper into .git/hooks/pre-commit.
[git-grass] Initialization complete. Your next commit will verify focus interval.

git grass status [--json]

Inspection

Inspects your repository break metrics: minutes elapsed since last verified outdoor walk, configured interval threshold, active session state, and whether your next commit will trigger a break.

terminal — status 
$ git grass status
[git-grass] Status:
  Last break completed: 74 minutes ago
  Configured interval:  60 minutes
  Minimum walk duration: 10 minutes
  Break due:            YES (next git commit will require outdoor break)
  Active session server: None (ready)

git grass check [--port <number>]

Hook Gate

The core pre-commit evaluation gate. Executed automatically by Git when you invoke git commit. If focus time is under the configured threshold, it exits immediately with return code 0. If a break is due, it snapshots staged tree SHA-1, starts the local pairing server, and displays QR code.

terminal — check intercept 
$ git commit -m "feat(auth): add OAuth2 provider"
[git-grass] Focus interval exceeded (74m >= 60m).
[git-grass] Commit paused. Staged tree SHA-1 fingerprinted: 4b825dc642cb...
[git-grass] Scan QR code with your phone or visit:
  http://192.168.1.48:4242/session/grass-7c42
[git-grass] Waiting for outdoor break completion (min: 10m)...

git grass config [key] [value]

Configuration

Reads or modifies repository configuration parameters in .git-grass/config.json: breakIntervalMinutes, defaultDurationMinutes, autoPush, port, hostedApiUrl.

bash — config 
git grass config breakIntervalMinutes 90     # Set 90m focus block
git grass config defaultDurationMinutes 15   # Require 15m outdoor walk
git grass config autoPush true               # Auto-push after commit unlock

git grass doctor

Diagnostic

Validates Node runtime version, checks Git path and repository state, checks pre-commit hook file permissions, verifies local network IP resolution, tests hosted AI endpoint connectivity, and confirms bundled offline challenge catalog integrity.

terminal — doctor 
$ git grass doctor
[doctor] Running environment diagnostic:
  [PASS] Node.js runtime: v20.11.0 (>= 18.0.0 required)
  [PASS] Git binary: 2.43.0 in PATH
  [PASS] Repository root: C:/Users/Admin/projects/cache (worktree active)
  [PASS] Hook status: .git/hooks/pre-commit contains git-grass gate
  [PASS] Network interface: 192.168.1.48 (IPv4 LAN address bound)
  [PASS] Offline catalog: 15 curated challenges loaded
  [PASS] Hosted AI backend: Render service healthy (HTTP 200)
All diagnostics passed. System ready.

git grass challenge [--test] [--category <name>]

Preview

Tests and previews challenge generation directly without initiating a pre-commit block or running a session timer. Validates that returned challenges adhere to the OutdoorChallengeSchema Zod contract.

terminal — challenge 
$ git grass challenge --category systems
[git-grass] Challenge generated:
  Title:      Kinetic Topology & Flow Walk
  Category:   systems
  Duration:   15 minutes (Phone-Free)
  Instructions:
    1. Step outside into open air for 15 minutes.
    2. Walk toward a pathway intersection or trail bifurcation.
    3. Observe how physical pathways route pedestrian flow without centralized locks.
  Reflection:
    "How does physical pedestrian queueing compare to partition bottlenecks in your cluster?"

git grass uninstall [--yes]

Removal

Safely removes git-grass hooks from the current repository without damaging other pre-commit tools. Restores your original pre-commit hook script and removes .git-grass/ config and cache.

Tech Stack & How It Was Built

git-grass is engineered with a strict minimal-dependency philosophy to guarantee zero runtime baggage and maximum developer trust:

  • TypeScript & Node.js ES Modules: Strict typing across all CLI commands, schemas, and network transports. Zero build compilation needed at user runtime.
  • Git Plumbing Architecture: Instead of fragile porcelain scraping, git-grass interacts with low-level Git plumbing: git write-tree to compute index SHAs, git rev-parse for repository boundaries, and git commit-tree for atomic commits.
  • Local Native HTTP Server: Zero Express or external web frameworks. A pure Node.js http.createServer daemon listening on local port 4242, with cryptographic token validation using crypto.timingSafeEqual.
  • Zod Runtime Schema Validation: Every generated outdoor activity is checked against OutdoorChallengeSchema before presentation to ensure safety, duration (>= 10m), and phone-free compliance.
  • Hosted AI (Render + Backboard): Deployed on Render's Free tier using Backboard inference with in-memory TTL caching and rate-limiting. Strictly operates within ₹0 in additional costs.

Staged Index Fingerprinting

When a break is enforced, git-grass immediately executes git write-tree to compute the cryptographic SHA of your current staging index.

When you return from outside and submit your commit from your phone, git-grass re-verifies the index hash before committing. If any staged file was modified or altered while you were outside, the commit halts immediately to prevent committing unexpected changes.

Local Wi-Fi Pairing Architecture

When a break triggers, your workstation starts a local HTTP server bound to your local area network (LAN) address (e.g., 192.168.1.48:4242). Communication between your phone and your computer stays strictly inside your local Wi-Fi network. No tokens or URLs pass through public servers.

Git Hook Architecture & Reentrancy Guard

When your outdoor break completes and git-grass triggers the final commit, it prevents infinite recursive hook loops using an internal environment flag:

bash — hook guard logic 
if [ "$GIT_GRASS_BYPASS" = "1" ]; then
  exit 0
fi

Hosted AI Setup (Render + Backboard)

git-grass connects to a lightweight cloud API deployed on Render's Free tier, using Backboard to generate project-aware outdoor prompts without any local AI runtime:

  • Zero Cost: Operates entirely within free tier allowances and existing credits (₹0 additional spending).
  • Strict Privacy: Only file extension names and high-level project domain metadata are sent. Your source code, diffs, and repository contents never leave your machine.

Deploying via render.yaml

  1. Fork or connect the repository to Render.
  2. Select New + → Blueprint and select the repository. Render automatically reads render.yaml.
  3. Add your Backboard API key in the Render Dashboard environment settings: BACKBOARD_API_KEY=<key>.
  4. Deploy the web service. Update your local config with git grass config hostedApiUrl https://your-service.onrender.com.

Bundled Offline Catalog

git-grass is offline-first. If no internet connection is available, or if the hosted inference provider is unreachable, git-grass instantaneously switches to the bundled library of curated engineering challenges spanning systems, web, ML, graphics, and audio.

Emergency Commit Bypass

If production is down and an urgent hotfix or security patch must be deployed without taking a break, use Git's standard pre-commit bypass flag:

bash 
git commit --no-verify -m "fix: critical production hotfix"

Troubleshooting Guide & FAQ

Phone cannot open the QR code URL?
Ensure your computer and phone are connected to the same Wi-Fi router. If you are on an enterprise or university network with client isolation enabled, turn on your phone's personal hotspot and connect your computer to it.
Port 4242 is already in use by another application?
Change the default port in your configuration: git grass config port 5050.
Can git-grass be used with Husky or lint-staged?
Yes. git grass init wraps your existing hook script and executes Husky or linters before or after the break gate.
