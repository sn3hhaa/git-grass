Development Plan

git-grass Project Roadmap

Track delivered capabilities alongside planned milestones for git-grass. Synchronized with project releases.

v0.1.0 & v0.1.1 Completed

Core Git Gate & CLI

  • Non-destructive Git pre-commit hook wrapper
  • Staged tree index SHA fingerprinting via git write-tree
  • Safe process execution with zero shell injection
  • Local Express HTTP session server with crypto tokens
  • Mobile web interface with authoritative workstation timer
  • CLI commands: init, status, check, config, doctor, uninstall
  • Curated offline fallback challenge library
v0.2.0 Completed

Hosted AI Backend (Render + Backboard)

  • Zero-laptop AI setup (no Ollama, Gemma, or Docker required)
  • Render Web Service blueprint (render.yaml) for Free tier
  • Backboard API integration using Gemini 2.0 Flash
  • 1-hour TTL in-memory challenge cache (credit safeguard)
  • Sliding-window IP rate limiter (15 req/min)
  • CLI doctor diagnostic check with cold-start awareness
  • Automated test suite across all modules
v0.3.0 In Progress

Audio Chimes & Distribution

  • Cross-platform terminal audio notification on interval completion
  • Global npm registry publication (git-grass@latest)
  • Git worktree multi-branch session coordination
  • Expanded local LLM backends (llama.cpp and Apple MLX)
v1.0.0+ Planned

Team Collaboration & Streaks

  • Coordinated break sessions for remote pair programming
  • SVG badge generator for README ("Touch Grass" commit streak)
  • Seasonal outdoor observation packs (autumn, winter, spring)
  • Optional Web Bluetooth pedometer synchronization
