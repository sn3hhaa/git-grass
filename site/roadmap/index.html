git-grass Project Roadmap

Track currently delivered capabilities alongside planned milestones for git-grass. Synchronized with docs/ROADMAP.md.

v0.1.0 & v0.1.1 • Delivered & Verified

Core Git Gate & CLI

  • ✓ Non-destructive Git pre-commit hook wrapper
  • ✓ Staged tree index SHA fingerprinting (git write-tree)
  • ✓ Terminal ANSI QR code generation with local LAN URL
  • ✓ Local Express HTTP session server with crypto tokens
  • ✓ Mobile web interface with authoritative workstation timer
  • ✓ Mobile check-in with commit message entry
  • ✓ CLI commands: init, status, check, start, verify, config, uninstall
  • ✓ Curated offline fallback challenge library
v0.2.0 • Delivered & Verified

Hosted AI Backend (Render + Backboard)

  • ✓ Zero-laptop AI setup (no Ollama, Gemma, or Docker needed)
  • ✓ Render Web Service blueprint (render.yaml) for Free tier
  • ✓ Backboard API integration using Gemini 2.0 Flash
  • ✓ 1-hour TTL in-memory challenge cache (credit safeguard)
  • ✓ Sliding-window IP rate limiter (15 req/min)
  • ✓ Thinking Machines Tinker evaluated & disabled by default
  • ✓ CLI doctor diagnostic check with cold-start awareness
  • ✓ 43 passing automated tests across all modules
v0.3.0 • Near-Term Planned

Audio Chimes & Route Suggester

  • ⏳ Cross-platform terminal audio gong when timer expires
  • ⏳ Optional OpenStreetMap public walking path suggester
  • ⏳ Expanded local LLM backends (llama.cpp and Apple MLX)
  • ⏳ Git worktree multi-branch session coordination
  • ⏳ npm registry publication (git-grass@latest)
v1.0.0+ • Long-Term Explorations

Team Wellness & Streaks

  • ⏳ Optional Web Bluetooth step counter synchronization
  • ⏳ SVG badge generator for README ("Touch Grass" commit streak)
  • ⏳ Coordinated break sessions for remote pair programming pairs
  • ⏳ Seasonal outdoor observation packs (autumn, winter, spring)
