git-grass Changelog

All notable changes to this project are documented in this file, adhering to Semantic Versioning.

[0.2.0] — 2026-10-10

Major Milestone: Hosted AI via Render + Backboard with ₹0 Laptop Setup

Added

  • Render-Hosted AI API Backend: Production Express service in src/hosted/ with /health and POST /api/challenge endpoints, 25kb body limit, CORS, and graceful shutdown.
  • Backboard AI Provider: Production integration in src/hosted/providers/backboard.ts calling Backboard API (Gemini 2.0 Flash) with configurable models and prompt formatting.
  • Credit & Cost Safeguards: In-memory 1-hour TTL cache (1000 items) and 15 req/min sliding-window rate limiter protecting API credits from abuse or duplicate calls.
  • Thinking Machines Tinker Evaluation: Evaluated Tinker framework; safely kept disabled by default (isConfigured() === false) to protect developer credits from GPU sampling costs.
  • CLI Hosted AI Integration: Client module src/challenge/hosted-client.ts with automatic failover, hostedBackendUrl configuration key, and git grass doctor cold-start diagnostics.
  • Automated Test Suite Expansion: 18 new automated tests in tests/hosted-backend.test.ts bringing the total test suite to 43 passing tests.
  • Public Marketing & Documentation Website: Complete responsive, mobile-first website in site/ with interactive terminal demo, challenge showcase, documentation, architecture, and FAQ.

[0.1.1] — 2026-10-10

Added

  • git grass doctor diagnostic command to audit Node.js, Git, local API connectivity, model presence, and fallback datasets.
  • git grass challenge [--test] command to preview and schema-validate project-aware challenges without triggering a Git commit.
  • Mocked AI test suite verifying prompt confidentiality and JSON validation.

[0.1.0] — 2026-10-10

Initial Release

  • Core CLI with Commander.js: init, status, check, start, verify, config, uninstall.
  • Git commit pre-commit hook gating with staged tree fingerprinting (git write-tree).
  • Local Express HTTP server (:4242) and terminal ANSI QR code generation.
  • Lightweight 10-state mobile web app on local LAN Wi-Fi with authoritative workstation timers.
  • Curated offline fallback challenge library (7 domain challenges).
