Quickstart

Begin in 60 seconds.

Install globally via npm or initialize inside any existing Git repository.

Terminal — Global Install 
# Install CLI globally
npm install -g git-grass

# Enable pre-commit outdoor gate in your repository
git grass init

# Verify local LAN environment
git grass doctor
