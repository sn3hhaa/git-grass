Workflow

How git-grass Works

A natural wellness friction point placed right where your cognitive work pauses: your Git commit.

1

Work Normally

Write code, execute tests, and make edits in your favorite editor. git-grass runs zero background surveillance daemons and consumes zero CPU while you write.

2

Gate Triggers on Commit

When your focus interval expires (default: 60 mins), your next git commit is safely held. The pre-commit hook generates an ANSI QR code and binds a temporary session server to your local Wi-Fi.

3

Step Outdoors (10m+ min)

Scan the terminal QR code with your phone. Read a project-aware observational challenge. Lock your phone screen, put it in your pocket, and step outside into sunlight and fresh air.

4

Check-in & Ship

Return after at least 10 minutes. Submit your reflection and commit message on the mobile interface. The workstation validates staging integrity and executes the atomic commit.

Capabilities

Built for Real Developer Workflows

Engineered with safety, privacy, and zero-bullshit engineering standards.

🛡️

Staged Index Fingerprinting

Uses git write-tree to compute a cryptographic tree SHA of your staging area before your break. Guarantees files can never be corrupted, lost, or silently changed during your walk.

☁️

Hosted AI via Backboard

Deploy the included Render service to generate AI challenges using Backboard API (Gemini 2.0 Flash). Requires zero local AI downloads, zero Ollama, zero Docker, and zero GPU memory on your laptop.

📦

Curated Offline Fallbacks

Bundles 7 domain-specific outdoor challenges across Systems, Web, GameDev, Audio, and ML. If your network is down or the cloud service times out, git-grass falls back instantly without stalling.

⏱️

Authoritative Workstation Timer

Timing enforcement is calculated on your workstation laptop, not on the phone. Mobile clock manipulation cannot bypass the strict 10-minute minimum break requirement.

🔒

Zero Shell Injection

All Git commands execute via child_process.execFile with argument arrays. User input and commit messages from the phone can never escape into shell commands.

📵

Screen-Free by Design

git-grass is not a mobile dashboard or a social feed. The phone explicitly tells you to lock your screen and observe your physical outdoor surroundings.

Challenges

Thematic Outdoor Challenges

Observational breaks tailored to your project's technical domain. Every task is 100% physical, screen-free, safe, and outdoor-oriented.

Systems 15 min walk

Kinetic Topology & Flow Walk

  1. Step outside to a pathway intersection or look at tree branch bifurcations.
  2. Observe how pedestrian traffic or rainwater flows without central coordination.
  3. Notice bottlenecks where flow naturally queues or disperses.
"How does physical pathway congestion compare to partition bottlenecks in your cluster architecture?"
Web & Frontend 15 min walk

Luminance & Contrast Stroll

  1. Step outside into daylight and observe sharp shadow boundaries cast by buildings or trees.
  2. Notice how squinting changes apparent contrast between lighted surfaces and deep shade.
  3. Observe natural color palettes without looking through a glass screen.
"Which natural boundary had the highest luminance contrast, and how did your eyes adapt?"
GameDev 15 min walk

Surface Roughness & Shading Walk

  1. Walk outside and examine three distinct natural textures: tree bark, stone, and wet leaves.
  2. Observe how sunlight shifts from specular sheen to diffuse scattering as you change your viewing angle.
  3. Notice micro-geometry that cannot be captured by simple normal maps.
"Which organic texture had the most intricate light scattering behavior?"
Machine Learning 15 min walk

Pattern & Texture Observer

  1. Take a quiet outdoor stroll and observe repeating organic patterns (leaf veins, ripple formations).
  2. Notice lighting angles and edge definitions that differentiate one cluster from another.
  3. Do not photograph them—use your biological memory and visual cortex.
"What distinctive edge or feature made one natural pattern immediately recognizable?"
Audio & DSP 12 min walk

Acoustic Horizon Deep Listening

  1. Find an outdoor bench or quiet standing spot. Close your eyes for 5 full minutes.
  2. Identify the closest sound (wind, breathing) versus the furthest audible sound (traffic, birds).
  3. Listen for phase interference, echo reflections from nearby walls, and high-frequency roll-off.
"What was the furthest sound source you could perceive, and what acoustic obstacles did it pass?"
Security Boundary

Strict Privacy Guarantees

What happens locally versus what touches the cloud.

Data / Resource Local Workstation Render Hosted AI Privacy Guarantee
Source Code & Diffs ✓ Stays 100% Local ✗ Never Transmitted Zero code, diffs, or file contents are ever uploaded to any cloud service.
Git Commits & SSH Keys ✓ Local Execution ✗ No Access The cloud backend never touches Git. The local CLI executes all Git commands.
Mobile Session Server ✓ Local Wi-Fi (:4242) ✗ No Public Tunnels Binds strictly to your LAN IP. No ngrok, Cloudflare tunnels, or public endpoints.
Repository Metadata ✓ Extracted Locally ✓ Bounded Subset Only repo name, broad category (e.g. systems), and duration are sent to AI.
API Keys & Secrets ✗ Zero Keys in CLI ✓ Render Secrets Only BACKBOARD_API_KEY resides exclusively in Render server environment.
Get Started

Installation & Quickstart

Set up git-grass in your repository in under two minutes.

1. Clone and Install git-grass

bash 
git clone https://github.com/sn3hhaa/git-grass.git
cd git-grass
npm install
npm run build

2. Initialize in Any Git Repository

Navigate to any project repository where you want outdoor break enforcement:

bash 
# Run init to install the non-destructive pre-commit gate:
node /path/to/git-grass/dist/cli/index.js init

# (Optional: link globally with npm link to run 'git grass' anywhere)
cd /path/to/git-grass && npm link
git grass init

3. Configure Break Intervals

bash 
git grass config breakIntervalMinutes 60      # Trigger after 60 min focus
git grass config defaultDurationMinutes 15    # Default 15 min walk (min 10)

4. Connect Your Hosted AI (Optional — ₹0 Setup)

If you deploy the included render.yaml with your Backboard key:

bash 
git grass config hostedBackendUrl https://your-service.onrender.com
git grass doctor
