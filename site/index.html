WORKFLOW

A natural rhythm for building.

Three concise steps designed to integrate intentional physical recovery into everyday source control.

01

Trigger a break

Run git grass or trigger your pre-commit hook after your focus interval expires. Git-Grass finger-prints your staged index safely in memory.

$ git commit -m "feat: cache" [git-grass] Break interval reached. Staged index preserved in memory.
02

Complete an outdoor challenge

Scan the terminal session link with your phone over local Wi-Fi. Step outside into open air for a 10-minute screen-free reflection tailored to your code.

Outdoor Challenge
Kinetic Topology Walk
Observe pedestrian flow at intersections to rethink hash routing.
03

Return and commit

Check in from your phone. Workstation verifies cryptographic token equality, releases the lock, and executes your commit atomically.

[ok] Token verified (constant-time). [ok] Staged tree SHA-1 verified. [main 8e4b2] commit created atomically.

Project-aware outdoor challenges

Write custom intervals and rules

Configure focus intervals, minimum outdoor walk durations, and verification rules per repository.

# Set focus window to 90 minutes git grass config --interval 90m # Set outdoor walk duration git grass config --duration 15m # Verify local LAN environment git grass doctor
