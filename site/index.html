git-grass is a Git-native outdoor break enforcement tool. When your focus interval expires, your next commit is paused until you step outside for a 10-minute walk with an AI-tailored reflection prompt.

Workflow

How it works

Five simple steps to safeguard focus and return with clarity.

01

Install git-grass

Install the CLI globally or initialize inside your repository with one command.

02

Work normally

Write code, stage files, and make commits without disruption during your focus interval.

03

Pause on expiry

When your interval passes, the pre-commit hook halts execution and fingerprints your staged tree.

04

Step outside

Take a 10-minute walk with an AI-generated prompt tied directly to your codebase diff.

05

Resume and ship

Check in from your phone on local Wi-Fi. Your commit completes atomically and your workstation unlocks.

Technical Architecture

Built for developer integrity

Reliable, lightweight tools designed to fit naturally into existing Git workflows.

Pre-commit Integrity

Fingerprints staged tree SHA-1 before unblocking to prevent race conditions or out-of-band modifications.

Zero Local AI Overhead

Hosted inference via Render and Backboard API requires no Docker, Ollama, Gemma, or local model downloads.

Cryptographic Token Auth

Timing-safe cryptographic token verification isolates the local session server from unauthorized local network requests.

Phone-Free Mobile Timer

Lightweight mobile web interface accessible over local Wi-Fi without creating accounts or storing data in the cloud.

Project-Aware Prompts

Context analysis inspects changed file paths and summary diffs to generate relevant outdoor analogies for your stack.

Fail-Open Safety Guarantee

Standard git flags like --no-verify and environment bypasses ensure urgent production fixes are never delayed.

Getting Started

Installation

Get up and running in under a minute with zero configuration required.

bash — install & initialize 
# 1. Clone repository and install dependencies
git clone https://github.com/sn3hhaa/git-grass.git
cd git-grass && npm install && npm run build

# 2. Initialize in your active Git repository
node dist/cli/index.js init

# 3. Verify environment and diagnostics
node dist/cli/index.js doctor

Frequently asked questions

Common inquiries regarding workflow, safety, and integration.

git-grass respects standard Git emergency bypass conventions. You can pass the standard --no-verify flag or set GIT_GRASS_BYPASS=1 in your environment. Production fixes will never be trapped or blocked by an active interval.

No. git-grass is designed specifically to require zero local AI runtimes. It uses a hosted cloud service on Render with the Backboard API when available, and automatically falls back to an offline bundled challenge library if network access is absent.

No code contents or commit diffs are transmitted to cloud endpoints. The challenge generator only sends high-level file extensions and project category labels (such as "systems" or "web") to generate tailored reflection prompts.

git-grass is cross-platform and tested across Windows (PowerShell and Git Bash), macOS (Zsh and Bash), and Linux distributions running Node.js 18 or newer.
