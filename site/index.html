Workflow

A better rhythm for building.

Five simple steps to safeguard focus and return with clarity.

01

Install Git-Grass

Install the CLI globally or link inside your repository in under a minute.

02

Work normally

Write code, stage files, and make commits without disruption while inside your focus interval.

03

Reach interval

When your configured interval expires, your pre-commit hook pauses execution and fingerprints your staged tree.

04

Outdoor challenge

Scan the terminal session link with your phone and step outside for a 10-minute screen-free reflection.

05

Continue workflow

Check in from your phone on local Wi-Fi. Your commit executes atomically and your workstation unblocks.

Core Capabilities

Built for developer integrity

Reliable, lightweight tools designed to fit naturally into existing Git workflows.

Git-native commit gate

Pre-commit hook intercepts commits when your configured focus interval expires, preventing endless screen fatigue.

Configurable intervals & durations

Customize focus windows (60 to 120 minutes) and outdoor break durations (10 to 30 minutes) per repository.

Project-aware outdoor challenges

Diff and package analysis generates stack-relevant analogies so physical walks refresh your mental models.

Optional hosted AI generation

Cloud inference via Render and Backboard API requires zero local model downloads, Docker, or GPU runtimes.

Bundled offline challenge fallback

Comprehensive built-in challenge catalog ensures full functionality when working offline or off-grid.

Staged-tree protection & local Git

Cryptographic tree SHA-1 validation prevents race conditions and ensures uncommitted edits are never altered.

Setup

Getting Started

Install globally or initialize within your active Git repository.

bash — clone & initialize 
# 1. Clone repository and install dependencies
git clone https://github.com/sn3hhaa/git-grass.git
cd git-grass && npm install && npm run build

# 2. Initialize in your active Git repository
node dist/cli/index.js init

# 3. Verify environment and diagnostics
node dist/cli/index.js doctor
